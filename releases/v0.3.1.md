# engineering-memlog v0.3.1

This patch makes Memlog's purpose clear in compact plugin lists. The first line
now explains the outcome—durable memory of verified debugging lessons across
projects—before describing any implementation details.

## Changed: the plugin description now starts with the reason to install

Claude Code now presents Engineering Memlog as:

> Gives Claude a durable memory of verified debugging lessons across projects,
> so it can reuse hard-won knowledge instead of starting over.

The Claude marketplace entry uses the same wording and the human-readable
`Engineering Memlog` display name. The portable Agent Plugins and Codex
manifests use an agent-neutral version of the description, and Codex's compact
and detailed descriptions now lead with cross-project reuse too.

This release does not change runtime behavior, the lesson schema, storage, or
the retrieval algorithm.

## Upgrade

```text
claude plugin marketplace update engineering-memlog
claude plugin update engineering-memlog@engineering-memlog
```

Then start a new Claude Code session so it loads the updated plugin metadata.
